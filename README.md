
# NoahLang

NoahLang is a general-purpose programming language. It has variables, functions, closures, loops, records, lists, and error handling. Every block opens with a word and closes with `end <word>` — the code reads like what you meant.

Its first standard library — **Forge** — turns NoahLang into a web development tool. You describe a page with functions like `head1`, `para`, `section`, and `card`, and Forge generates complete HTML.

```noah
pull "Forge.noah"

page("Hello")
head1("Welcome to NoahLang")
para("This page was generated by a NoahLang program.")
done()
serve(3000)
```

But Forge is not the language. The language itself is domain-neutral. It runs on Node.js, it reads `.noah` files, it executes them. What they *do* depends on which libraries they pull. Today that's Forge. Tomorrow it could be a data library, a desktop UI library, a mobile UI library, or something nobody has thought of yet.

**Current version:** 2.0.7

## Install

NoahLang requires [Node.js](https://nodejs.org/) 16 or later.

```bash
npm install -g noahlang
```

Check it worked:

```bash
noah --version
```

You should see:

```
NoahLang 2.0.7
```

That installs three things:

- The `noah` command (on your PATH, available from any folder)
- **Forge** — the web library — in `~/.noahlang/lib/Forge.noah`
- `style.css` — a default stylesheet — in `~/.noahlang/lib/style.css`

If you don't have Node.js, use the installer script:

**macOS / Linux:**

```bash
curl -fsSL https://raw.githubusercontent.com/NoahKahenge/NOAHLANG/main/install/install.sh | bash
```

**Windows (PowerShell):**

```powershell
iwr -useb https://raw.githubusercontent.com/NoahKahenge/NOAHLANG/main/install/install.ps1 | iex
```

The installer checks for Node.js, installs it if missing, then installs NoahLang.

## Quick start

Create a file called `hello.noah`:

```noah
write "Hello, world!"
```

Run it:

```bash
noah hello.noah
```

Output:

```
Hello, world!
```

Create a file called `site.noah`:

```noah
pull "Forge.noah"

page("My Site")
head1("Welcome")
para("This is my first NoahLang website.")
done()
serve(3000)
```

Run it with watch mode:

```bash
noah --watch site.noah
```

The browser opens to `http://localhost:3000/`. Edit `site.noah`, save, and the browser reloads automatically.

## What you can build

**Command-line tools and system apps** — today, with no extra libraries. A NoahLang program that doesn't `pull "Forge.noah"` is a CLI script. It reads files, writes files, processes data, prints to the terminal.

```noah
let content = readFromFile("data.txt")
let count = 0
for ch in content
    if ch == "\n"
        set count = count + 1
    end if
end for
write "Read " + str(count) + " lines"
writeToFile("count.txt", str(count))
```

**Websites and web apps** — today, with Forge. Page generation, event routing, hot reload, browser preview.

```noah
pull "Forge.noah"

page("Counter")
head1("Counter")
para("Current value: 0")
done()
serve(3000)
```

**Desktop apps** — today, by wrapping the HTML output in Electron. Native desktop libraries are planned, but the HTML approach works now because the output is already a complete page.

**Mobile apps** — today, by wrapping the HTML output in React Native. Same reasoning: the output is HTML, React Native displays it.

**Games, data tools, networking, IoT** — none of these exist as libraries yet, but none of them *require* a language change. A `game.noah` library wrapping a canvas, a `data.noah` library for CSV and JSON, a `net.noah` library for sockets — each is a library, not a language modification. NoahLang has the primitives (functions, records, closures, error handling) that a library in any domain needs.

**NoahLang is general-purpose. It has one standard library so far. That's a fact about the library ecosystem, not a limit on the language.**

## Language reference

### Comments

```noah
// This is a comment
write "Hello"  // This is a trailing comment
```

### Variables

```noah
let name = "Noah"
set name = "Alice"
```

- `let` declares a **new** variable in the current scope.
- `set` reassigns an **existing** variable (searches enclosing scopes).
- Declaring the same name twice in the same scope is an error.
- Reassigning an undeclared variable is an error.

### Values

| Type | Examples |
|---|---|
| Number | `42`, `3.14`, `-7` |
| String | `"hello"`, `'hi'`, `"line\nbreak"` |
| Boolean | `true`, `false` |
| Null | `null` |
| List | `[1, 2, 3]`, `["a", "b"]`, `[]` |
| Record | `record person` … `end record` |
| Range | `0..10` (only used in `for`) |

### Strings and interpolation

```noah
let name = "Noah"
let age = 42

write "Hello, {name}!"
write "Next year: {age + 1}"
write "Literal braces: \{x\}"
```

Any `{expr}` inside a string is evaluated and inserted. Escape a literal brace with `\{` and `\}`.

Escape sequences: `\n \r \t \b \f \v \0 \\ \" \' \uXXXX`.

### Operators

From **highest** to **lowest** precedence:

| Level | Operators | Notes |
|---|---|---|
| 1 | `( )` `[ ]` | Grouping, indexing, field access |
| 2 | unary `-` `+` | |
| 3 | `*` `/` `%` | Numbers only. Division by zero is an error. |
| 4 | `+` `-` | `+` concatenates if either side is a string. |
| 5 | `==` `!=` `<` `>` `<=` `>=` | Strict equality. |
| 6 | `and` `or` `not` | Short-circuit logic. |
| 7 | `then` | Pipeline: `x then f` means `f(x)`. |

### Lists

```noah
let names = ["Alice", "Bob", "Charlie"]
write names[0]        // "Alice"
write len(names)      // 3
```

### Records

```noah
record person
    name: "Noah"
    age: 42
end record

write person.name     // "Noah"
write person["age"]   // 42
```

Records can contain lists and other records. Lists can contain records and other lists.

### Ranges

`0..10` is a range from `0` to `9` (exclusive end). Ranges are used only in `for`.

```noah
for i in 0..5
    write i
end for
// prints 0 1 2 3 4
```

### Conditionals

```noah
if score >= 90
    write "A"
else if score >= 80
    write "B"
else
    write "C"
end if
```

- Opens with `if cond`.
- Chains with `else if cond`.
- Closes with `end if`.
- The `else` branch is optional.

### Loops

**`for`** iterates over a list, string, or range:

```noah
for name in ["Alice", "Bob"]
    write name
end for

for i in 0..3
    write i
end for

for letter at i in ["a", "b", "c"]
    write str(i) + ": " + letter
end for
```

**`while`** loops while a condition is true:

```noah
let n = 0
while n < 5
    write n
    set n = n + 1
end while
```

**`repeat`** loops a fixed number of times:

```noah
repeat 3 times
    write "hello"
end repeat

repeat 3 times as i
    write i
end repeat
```

**Loop control:**

```noah
for x in [1, 2, 3, 4, 5]
    if x == 3
        continue
    end if
    if x == 5
        break
    end if
    write x
end for
```

- `break` exits the current loop.
- `continue` skips to the next iteration.

### Functions

```noah
define greet(name)
    write "Hello, " + name
end define

greet("Noah")
```

- Opens with `define name(args)`.
- Closes with `end define`.
- The last expression in the body is the return value.
- Use `return` for an early return.

```noah
define square(n)
    return n * n
end define

write square(7)    // 49
```

Functions are **first-class values**. They are **lexically scoped** — they close over the environment where they were defined.

### Error handling

```noah
attempt
    let data = readFromFile("missing.txt")
    write data
recover with err
    write "Error: " + err
end attempt
```

To throw an error:

```noah
define divide(a, b)
    if b == 0
        fail with "cannot divide by zero"
    end if
    return a / b
end define

attempt
    write divide(10, 0)
recover with err
    write "Caught: " + err
end attempt
```

### Named blocks

Any function can be used as a named block:

```noah
start section("services")
    head2("What we do")
    para("Some content")
end section
```

- `start name(args)` calls `name(args)`, then runs the indented body, then calls the matching closer function.
- Every `end <name>` must match the most recent `start <name>`.

### Imports

```noah
pull "Forge.noah"
pull "lib/math.noah"
```

- `pull` loads another `.noah` file.
- Paths are relative to the file that says `pull`.
- If not found locally, `pull` searches `~/.noahlang/` and `~/.noahlang/lib/`.
- Each file is loaded once.
- Circular `pull`s are an error.

## Built-in functions

| Function | Description |
|---|---|
| `write(...)` / `print(...)` | Print values, space-separated |
| `len(x)` | Length of a string, list, or record |
| `str(x)` | Convert to a string |
| `num(x)` | Convert to a number |
| `bool(x)` | Convert to a boolean |
| `append(list, value)` | New list with `value` added |
| `remove(list, index)` | New list with `index` removed |
| `keys(record)` | List of a record's keys |
| `has(record, key)` | True if the record has `key` |
| `receive()` | Read one line from stdin |
| `collect(...)` | Build a list (same as `[...]`) |
| `fail with "message"` | Throw an error |
| `writeToFile(path, content)` | Write a file |
| `readFromFile(path)` | Read a file |
| `openInBrowser(path)` | Open a file or URL in the browser |

## Forge — the web library

**Forge** is NoahLang's web framework. Load it with `pull "Forge.noah"`.

### Page structure

| Function | Emits |
|---|---|
| `page(title)` | Starts a new page |
| `done()` | Writes `index.html` and returns the HTML |

### Content

| Function | Emits |
|---|---|
| `head1(text)`, `head2`, `head3` | `<h1>`, `<h2>`, `<h3>` |
| `para(text)` | `<p>` |
| `line(text)` | `<span>` |
| `code(text)` | `<pre><code>` |
| `link(url, label)` | `<a href>` |
| `button(label, eventId)` | `<button onclick>` |
| `img(src, alt)` | `<img>` |
| `raw(html)` | Raw HTML (escape hatch) |

### Layout

| Function | Emits |
|---|---|
| `section(name)` | `<section class="name">` |
| `container()` | `<div class="container">` |
| `navStart(brand)` / `navItem(url, label)` / `navEnd()` | Navigation bar |
| `hero(title, subtitle, ctaLabel, ctaUrl)` | Hero header |
| `cardsStart()` / `card(title, body)` / `cardsEnd()` | Card grid |
| `columnsStart()` / `columnStart()` / `columnEnd()` / `columnsEnd()` | Two-column layout |
| `bulletsStart()` / `bullet(text)` / `bulletsEnd()` | Bullet list |
| `footer(brand, year)` | Footer |

Layout blocks are used with `start` / `end`:

```noah
start section("services")
    start container()
        head2("What we do")
        start cardsStart()
            card("Web development", "...")
            card("Data collection", "...")
        end cardsStart
    end container
end section
```

### Server and events

```noah
serve(3000)
```

Starts an HTTP server on port 3000, serving files from the current directory.

To wire a button to an event:

```noah
define onIncrement()
    set count = count + 1
    rebuild()
end define

button("Increment", "inc")
bindEvent("inc", onIncrement)
```

- `button(label, eventId)` produces a button that fetches `/__event?id=<eventId>` and reloads the page.
- `bindEvent(eventId, fn)` registers a handler for that event.
- When the button is clicked, the server runs the handler and the page reloads.

### Styles

Put CSS in a `style.css` file next to your `.noah` file. `done()` links it automatically:

```html
<link rel="stylesheet" href="style.css">
```

## The CLI

```bash
noah <file.noah>          Run a program
noah --watch <file.noah>  Run and re-run on file changes
noah --version            Print version
noah --help               Print help
```

**Watch mode** re-runs the program whenever the `.noah` file (or any file it pulls) changes. If the program calls `serve()`, the browser reloads automatically.

```
[watch] site.noah changed — reloading
[serve] listening at http://localhost:3000/
```

Press `Ctrl+C` to stop.

## Examples

### Hello world

```noah
write "Hello, world!"
```

### Counter

```noah
pull "Forge.noah"

let count = 0

define onIncrement()
    set count = count + 1
    rebuild()
end define

define rebuild()
    page("Counter")
    head1("Counter")
    para("Current value: " + str(count))
    button("Increment", "inc")
    bindEvent("inc", onIncrement)
    done()
end define

rebuild()
serve(3000)
```

### Factorial with clauses

```noah
define fact(0)
    return 1
end define

define fact(n)
    return n * fact(n - 1)
end define

write fact(10)    // 3628800
```

### Processing a list

```noah
define total(items)
    let sum = 0
    for item in items
        set sum = sum + item
    end for
    return sum
end define

write total([1, 2, 3, 4, 5])    // 15
```

### Reading input

```noah
write "What is your name?"
let name = receive()
write "Hello, " + name
```

### A record of a person

```noah
record person
    name: "Noah"
    age: 42
    hobbies: ["reading", "coding"]

write person.name
write person.age

for hobby in person.hobbies
    write "  - " + hobby
end for
```

## The build model

When you run `noah site.noah`:

1. The interpreter reads `site.noah`.
2. It executes every statement in order.
3. When it reaches `done()`, it writes `index.html` — the complete, final HTML.
4. When it reaches `serve(3000)`, it starts an HTTP server serving that HTML.

There is no runtime interpreter for the browser. The `.noah` file is a program that generates a document, not a document a browser interprets.

This is closer to a static site generator (Hugo, Jekyll) or a template engine (Jinja, ERB) than to a browser framework (React, Vue).

## What NoahLang is and isn't

**What it is:**

- A general-purpose programming language.
- A language with variables, functions, closures, loops, records, lists, error handling, and imports.
- A language whose syntax reads like English — every block named on both ends.
- A language with one standard library so far: Forge, the web framework.

**What it isn't:**

- A browser runtime like React or Vue. NoahLang programs run on the server (or your machine), not in the browser.
- A wrapper around another language. It has its own syntax, its own parser, its own runtime.
- A web-only language. Forge is a library. The language itself doesn't know what HTML is.

**What it can become:**

- A language for building web apps (works today).
- A language for building CLI tools (works today).
- A language for building desktop apps (via Electron — works today; native library planned).
- A language for building mobile apps (via React Native — works today; native library planned).
- A language for building anything else that a library can reach — games, data tools, networking, whatever comes next.

## Roadmap

- **v2.1** — more built-in functions: string methods, list methods, `map` / `filter` / `reduce`, JSON parse/stringify, HTTP client.
- **v2.2** — proper module system: `import { x, y } from "lib.noah"`, namespacing, private functions.
- **v2.3** — packaging and distribution: standalone installer scripts (done), more examples.
- **v3.0** — desktop apps via Electron integration, or a native `desk.noah` library.
- **v3.1** — mobile apps via React Native integration, or a native `phone.noah` library.
- **v4.0** — a transpiler that turns `.noah` into JavaScript, so web apps can run without a server.
